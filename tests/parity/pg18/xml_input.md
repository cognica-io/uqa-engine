# XML input, output and session reference

`capture_xml_input.py` uses Python 3 and libpq to capture 122 XML inputs and 27 SQL statements from PostgreSQL 18.4 on aarch64 Alpine, linked with libxml2 2.13.9-r2. The official `postgres:18.4-alpine` image used for capture has repository digest `sha256:9a8afca54e7861fd90fab5fdf4c42477a6b1cb7d293595148e674e0a3181de15`. Set `PG_XML_CONNECTION` to an explicit disposable connection and `PG_XML_LIBXML_VERSION` to its independently inspected libxml2 package version. The capture creates only a session-local temporary table and prepared definitions.

Inputs cover document/content selection, empty and mixed content, multiple roots, XML declarations and output normalization, Unicode and byte-order marks, namespace diagnostics, internal and external entities, malformed syntax and warnings. The fixture records the original stored value, serialized output, XML OID, SQLSTATE, primary message, detail and notices. SQL owner tests replay every field. Engine tests replay input and statement behavior through independently named Memory, SQLite native, SQLite KV and redb cases; separate durable tests reopen all three persistent providers and verify type identity, retained values and rollback.

Statement cases cover XML and array catalog identities, typed NULL, missing comparison operators, casts, assignment, prepared literal retention, runtime setting changes, array output and savepoint recovery. XML array-to-TEXT output exposed an element-cast shortcut: XML-to-TEXT binary coercion preserves a declaration, while array output must invoke `xml_out` and serialize it. The correction uses the shared typed array formatter.

PostgreSQL's XML parser behavior depends on its linked libxml2. A separate PostgreSQL 18.4 Debian instance using libxml2 2.9.14 rejected three document inputs accepted by the Alpine instance: an unknown encoding declaration with explicitly UTF-8 input, a leading UTF-8 byte-order mark, and that mark before an XML declaration. All 27 statement observations agreed. The committed fixture records the modern reference explicitly; the bundled 2.15.4 parser matches its input acceptance, output and diagnostics. PostgreSQL's [XML type contract](https://www.postgresql.org/docs/18/datatype-xml.html) and [XML implementation](https://github.com/postgres/postgres/blob/REL_18_STABLE/src/backend/utils/adt/xml.c) define the independent semantic reference.
