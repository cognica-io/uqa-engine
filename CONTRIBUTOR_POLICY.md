# Contributor Licensing Policy

UQA Engine uses Apache 2.0 for development sources and releases after 0.6.1, as described in [LICENSING.md](LICENSING.md). Cognica must retain sufficient rights to publish every accepted contribution under the project license and any separately agreed terms.

## Public-core commitment

Code accepted into the public UQA Engine core will remain available under at least one license approved by the Open Source Initiative. Commercial licensing will not withdraw or narrow open-source rights already granted for an accepted contribution.

## Copyrightable contributions of code and documentation

Before an external copyrightable contribution of code or documentation can be merged, its copyright holders must enter into a contributor agreement accepted by Cognica. The agreement must permit Cognica to use, modify, distribute, and sublicense the contribution:

- under Apache-2.0;
- under separate commercial terms; and
- under a future OSI-approved open-source license.

The agreement must also address patent rights needed to exercise those grants and must confirm that the contributor has authority to make the contribution. A corporate contributor must have authority from the relevant employer or rights holder.

Cognica has not yet published the execution workflow or final contributor agreement. Until that process is available, external copyrightable contributions of code or documentation will not be merged. This preserves the ability to operate every licensing path without later requesting retroactive permission.

## Contributions that do not require an agreement

The contributor agreement is not required merely to:

- open an issue or report a bug;
- provide a minimal reproduction that contains no original project code;
- suggest an idea or design direction;
- report a security vulnerability privately; or
- correct purely factual metadata that is not copyrightable.

Submitting third-party code, generated code with incompatible terms, or code copied from another project is not permitted unless its provenance and license have been reviewed and explicitly accepted.
