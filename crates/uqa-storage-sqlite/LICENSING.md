The complete terms are in [LICENSE](LICENSE), reproduced from the [Apache Software Foundation](https://www.apache.org/licenses/LICENSE-2.0).

## Earlier releases

Already published releases retain the licenses and additional permissions distributed with those releases. This change does not replace the license files or exception texts in existing release tags, source archives, or registry packages. In particular, the [0.6.1 licensing policy](https://github.com/cognica-io/uqa-engine/blob/v0.6.1/LICENSING.md) and its AGPL license and optional exceptions remain the reference for that release.

## Use and redistribution

Apache 2.0 permits commercial and noncommercial use, modification, and redistribution subject to its terms. Open-source and proprietary applications can use UQA Engine under the same license; no FOSS or noncommercial application exception is needed for Apache-licensed releases. Follow the license's copyright, patent, attribution, modification-notice, and redistribution conditions.

Separate agreements with Cognica, Inc. may provide support, warranties, or other negotiated terms. Such an agreement is not required solely because an application is proprietary or commercial. See [COMMERCIAL.md](https://github.com/cognica-io/uqa-engine/blob/main/COMMERCIAL.md).

## Third-party software

The project license applies only to material for which Cognica has authority to grant these rights. Dependencies, imported code, bundled libraries, dictionaries, models, and other third-party material retain their own licenses and notices. The imported PostgreSQL parser and regular expression crates retain their existing upstream licenses. Their license files and the bundled third-party attribution remain part of the applicable distributions.

## Package metadata and distributions

Project-owned Rust, Python, Node.js, WebAssembly, and C distributions use `Apache-2.0` metadata and include the Apache license and this policy. Package license notices identify the project license and preserve third-party attribution. The former UQA FOSS and noncommercial application exception files are not part of Apache-licensed distributions.

Version 0.6.2 is the first Apache-licensed release. Existing release tags, source archives, and registry versions retain their original licensing files.

## Contributions and the public core

Code accepted into the public UQA Engine core will remain available under at least one license approved by the Open Source Initiative. Separate commercial terms do not withdraw or narrow open-source rights already granted for a release.

The existing contributor-agreement requirement continues to apply to external copyrightable contributions of code or documentation. See [CONTRIBUTOR_POLICY.md](https://github.com/cognica-io/uqa-engine/blob/main/CONTRIBUTOR_POLICY.md).

Licensing and commercial inquiries may be sent to `jaepil@cognica.io`.
