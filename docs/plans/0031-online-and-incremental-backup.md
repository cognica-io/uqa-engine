### Incremental comparison

Common Storage now implements the baseline complete-inventory merge independently of the unfinished memory Engine selector. A compatible retained parent supplies authenticated object ranges for exact address/kind/length/digest matches. Changed and new units receive new ranges; deleted units disappear and explicit current tombstones remain. Candidate bytes are hashed once through a quota-bound encrypted spool, so no source reread or payload-sized resident buffer is required. An unchanged image writes only its new complete inventory. The [preservation argument](../design/backup-image-format.md#complete-incremental-inventories) establishes equality with the current full image and independence from ancestor manifests.

This comparison reads every current payload and reports source reads, hashes, reuse and new object bytes separately. Fingerprint acceleration, retention/GC, standalone copy, key rotation and public Engine jobs remain open. The complete Storage library passes 1,159 cases on macOS and 1,160 on Linux aarch64 with no failures or ignored cases.
