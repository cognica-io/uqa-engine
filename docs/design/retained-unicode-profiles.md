# Retained generic Unicode profiles

## Contract and ownership

A resolved analyzer descriptor is an immutable executable revision, not a request to recompile the diagnostic configuration with today's Unicode tables. `uqa-analysis` owns profile validation and execution. Engine and providers retain descriptors and their original transaction boundaries. New descriptors continue to select Unicode 16; restored descriptors can select the verified historical Unicode 17 profile. There is no database migration or descriptor/fingerprint rewrite. No crate dependency direction or feature requirement changes.

## Preservation argument

Let the term domain be finite sequences of Unicode scalars and isolated UTF-16 units. For retained profile p, define M_p(c) as its full scalar lowercase sequence, W_p(c) as its whitespace predicate, and C(c), I(c) as the historical cased and case-ignorable predicates. Unicode 16 uses pinned ICU 2.0 data. Unicode 17 uses the same M_16 outside the 28 complete UCD differences and the exact UCD replacement at each differing scalar. This partitions the scalar domain, so M_17 equals the historical Unicode 17 mapping everywhere. The independently captured exhaustive digest additionally checks implementation correspondence. The two official White_Space sets are equal, hence W_17 = W_16 and the shared tokenizer classifier is exact. Both historical profiles used these same C and I sets; their hashes remain validated rather than inferred from the version label.

For a capital sigma, the result is final sigma exactly when an original-input cased scalar precedes it through only ignorable scalars and no following original-input cased scalar exists through only ignorable scalars. The two forward cursors evaluate that same predicate for either profile. A raw UTF-16 unit is copied unchanged and clears context; valid surrogate pairs remain scalars. At every input position, the output is therefore the historical full mapping or the same contextual sigma mapping. Induction on input positions proves equality of the complete output sequence, including expansions and raw units. Token positions, source spans, terminal increments, morphology attributes and field-length policy are not modified by profile selection.

Let A_p be the retained analysis transformation and B any unchanged subsequent stage defined on its output. Pointwise equality A'_p(x) = A_p(x), including decorated token metadata, implies B(A'_p(x)) = B(A_p(x)); ordinary function composition remains associative and identity stages remain identities. No distributivity or commutativity of token streams or posting payloads is assumed. Exact index/search token equality preserves term membership, positions, frequencies, lengths and resulting scoring inputs; changes to a named definition cannot replace a field's retained revision. Descriptor canonical bytes and fingerprints are retained, so cache lookup preserves revision identity and distinguishes profiles whose mappings differ.

Validation resolves only the closed supported profile set and compares the entire expected runtime profile, including normalization and regex identities. Unsupported or mismatched profiles fail before cache publication. All runtime output still passes through the same admitted TermBuffer; the Unicode 17 lookup owns only a static sorted 28-entry table and performs bounded comparisons without allocation. Both source cursors advance monotonically, so n source elements require O(n) traversal and bounded polling intervals. Allocation and cancellation failures expose no partial output and release only owned reservations. Provider reopen, new writes and rollback preserve the existing catalog and transaction effects.

## Evidence

The [Unicode 16 reference](../../crates/uqa-analysis/tests/fixtures/unicode-16-reference.md) and [Unicode 17 reference](../../crates/uqa-analysis/tests/fixtures/unicode-17-reference.md) establish independent scalar/context/whitespace digests. Historical keyword, whitespace, standard, n-gram and English descriptors test byte-exact restoration, distinct cache identity, and strict rejection. SQLite native, SQLite KV and redb tests reopen a persisted historical named descriptor and frozen field binding, verify old postings and new writes, and roll back a write without replacing the binding. The deterministic regression manifest includes complete scalar output, raw-unit memory failures, bounded context work and cancellation. CI supplies Linux/macOS evidence for the final product source; these checks make no wall-clock speedup claim.
